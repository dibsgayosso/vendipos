# Cancelaciones y devoluciones
- Nunca borrar ventas.
- Motivo obligatorio.
- Devolución parcial o total por partida.
- No permitir devolver más de lo vendido menos devoluciones anteriores.
- Al completar una devolución, regresar existencias y crear stock_movement tipo return.
- El reembolso puede dividirse en varios métodos de pago y debe cuadrar con el importe devuelto.
- Cancelar/anular requiere permiso independiente y conservar trazabilidad.
- La UI debe solicitar autorización del usuario cuando el permiso correspondiente no esté presente.
